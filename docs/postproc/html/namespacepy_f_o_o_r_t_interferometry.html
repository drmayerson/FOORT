Converts FOORT output data to visibility amplitudes.

Parameters
FilePrefixThe prefix of the FOORT output files.
AnglesThe angles to calculate the radon transform at; angles are given as counter-clockwise from the +x axis
NrFilesThe number of files to load (default = 1).
FirstLineDescriptionWhether the first line of the file is a description (default = True).
VerboseWhether to print out progress information (default = True).
GridFractionThe fraction of the grid to use (default = 1).
TruncateRangeThe range to truncate the data to (default = None).
LimitRangeThe range to limit the data to (default = (0.0, 100000.0)).
EquatPassesRangeThe range of equatorial passes to select (default = None).
EquatPassesSelectionThe selection of equatorial passes to use (default = None).
RadonPaddingFactorThe factor to pad the radon transform by (default = 25).
FileOutputThe name of the file to save the visibility amplitudes to (default = None).
LightRingRadiusThe radius of the light ring, if one is present (default = None). When used, this separets "inner" and "outer" photon rings.
AngularSizeFull angular width of the screen in radians, i.e. the angle between the first and last pixel columns, which sit exactly on the screen edges (default = 50 microarcseconds, converted to radians).
EdgeWarningThresholdWarn if the largest intensity on the edge of the screen exceeds this fraction of the peak intensity, i.e. if the emission is cut off by the edge of the screen (default = 1e-2).
Returns
visamps: The normalized visibility amplitudes |V(u)| / V(0), with V(0) the total flux on the screen (one row per angle).

Two diagnostics are computed (and printed if Verbose): the retained flux fraction, i.e. the flux in each Radon projection relative to the total flux on the screen (should be 1), and the edge-to-peak intensity ratio. A warning is given if the former deviates from 1 by more than 1%, or if the latter exceeds EdgeWarningThreshold: emission reaching the edge of the screen means the field of view truncates the source, which affects V(0) and hence the normalized amplitudes.

Returns
baselines: The baselines of the visibility amplitudes corresponding to the visamps.
FirstLineInfo: The first line of the file, if applicable.

Calculates the complex visibility from a given radon transform.

Parameters
FOORTRadonThe radon transform to calculate the complex visibility from (one row per angle).
PaddingFactorThe factor to pad the radon transform by (default = 25); must be >= 1.
VerboseWhether to print out progress information (default = True).
sample_spacingThe spacing between samples in the radon transform (default = 1.0).
Returns
complvis: The complex visibility of the radon transform.
freqs: The frequencies of the FFT of the radon transform.

The complex visibility is calculated by taking the FFT of the radon transform, shifting it to center the zero frequency, and selecting only the positive frequencies.

Note
The padding factor is used to increase the resolution of the FFT; the padded length is rounded to the nearest integer.
The sample spacing is used to calculate the frequencies of the FFT. It corresponds to the pixel width in the original image.

Calculates the radon transform of a given FOORT emission grid.

Parameters
FOORTEmissionGridThe FOORT emission grid to calculate the radon transform of.
AnglesThe angles to calculate the radon transform at. Angles are given as counter-clockwise from the +x axis.
VerboseWhether to print out progress information (default = True).
Returns
radontransf: The radon transform of the FOORT emission grid, one row (projection) per angle.

The whole (square) grid is used, including its corners: each projection has length ceil(sqrt(2) N) for an N x N grid, and sums to the total flux on the screen (up to interpolation errors).
